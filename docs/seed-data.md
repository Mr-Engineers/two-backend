# Seed data

Generated by `python scripts/generate_seed_docs.py` from `app/seed/data.py` (do not edit by hand).

All values are **synthetic demo data**: fictional manufacturers, demo prices (not real offers or exchange rates) and demo stock levels. `country_of_origin` is a validated ISO 3166-1 alpha-2 attribute of each product; it is a demo attribute, not a statement about any real product on the market. The origin is independent from the shop country and from the manufacturer name.

Prices are gross (tax included) per sold pack. `minor` is the integer stored in the database.
